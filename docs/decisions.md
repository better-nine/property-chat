## [0주차] 백엔드를 Spring Boot로

- 결정: 서비스 본체는 Spring Boot + Spring AI, 일회성 데이터·평가 작업만 Python
- 대안: Python + FastAPI로 전체 구현
- 이유: 목표 포지션이 Spring 기반 서버 개발이고, LLM 기능과 Spring 기본기(계층 설계, 예외 처리, JPA, 테스트)를 한 프로젝트에서 함께 쌓을 수 있음
- 대가: LLM 관련 신기능·예제는 Python 쪽이 먼저 나오고, Langfuse 연동은 OpenTelemetry 설정이 필요함
